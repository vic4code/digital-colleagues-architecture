Phase goals，
從 Scheduled 到 Self-initiated。

PHASE 1

Scheduled work

人給 Task + Schedule

Schedule→Fixed output
Exit criteria

準時、無重複；無新素材可 Skip。

Reference prototype available
PHASE 2

Goal-driven work

人給 Goal + Acceptance criteria

Plan / Execute↻Validate
Exit criteria

有驗收證據才 Complete；否則 Continue / Blocked / Exhausted。

Planned · not implemented
PHASE 3

Self-initiated work

人給 Vision + Role + Permissions

Context→New proposal
Exit criteria

未逐件交辦；提案有來源、符合職責，交人決定。

Planned · not implemented

這是主動性成熟度，不是部署時程，也不是架構 repo 的 Phase 0–4。Time／event 可出現在三個階段。

「Phase 3 業界是零」怎麼讀？

你提供的研究在受查五框架、指定快照與「可調用介面＋從對話自行推斷」判準下，未確認現役完整機制。這不是對全市場永久宣告；Voyager 的環境 curriculum 也不能直接換算為此處的 P3。

OpenClaw 曾有 inferred commitments，已退役；既定目標續跑、plan 子步驟、人排的 queue 都不算嚴格自主跟進。

05 / CATHAY SCENARIOS & EVIDENCE

Cathay scenarios，
Use case → Validation。

法務／法遵：定期到期清單 → 交辦補齊送審資料 → 自行發現值得檢視的契約並提案。

國泰情境假設，未接實際內部資料。唯讀來源、私有收件匣、人審；不對外寄送。

Observability · Skip 還是 Failure？

產出多不代表主動性好。要知道它有沒有看、為何做或不做，以及漏掉什麼。

Precision · 提案有用嗎？

已評閱提案中，多少被人判定有用。

Recall · 機會有漏嗎？

用人工標註情境，檢查該想到卻沒想到的事。

Duplicate rate · 有重提嗎？

已處理、退回與延後的事，是否仍反覆出現。

Metrics · 指標與分母
指標定義避免誤讀
Wake coverage有結果的到期 occurrence／應到期 occurrence分 timer、event、human、inbox-open；模型呼叫數不是主動次數
Proposal usefulness人工判定有用／已評閱提案未讀另列；只看採納無法知道漏判
Opportunity recall有提出的標註機會／全部標註機會需離線標註集或定期人工抽查，不能從線上提案自算
Unsupported / Duplicate rate不合格提案／所有生成提案保留 W6 被擋的提案，才有分母
注意力與成本標題已讀、內容開啟、接受／退回／延後；每次有效提案成本不把開過等同有用；含生成後被擋成本
可靠性來源延遲、W 階段耗時、恢復時間、預算耗盡、cursor lag零模型不等於零資源成本；trace 是理由與證據，不存隱藏思考鏈
確定性測試→固定來源 replay→真實 adapter 整合→旁路提案＋人工評閱

90 項測試與 2 次真實整合是原 repo 的報告，本次未重跑，也不代表國泰業務效果已驗證。
