01 / START WITH A HUMAN

沒人交代，
你卻想到了。

「下午的簡報，
是不是還用著舊數字？」

一位準備下午會議的同事
人 · 從在意的事，想到下一件事
想到一件新工作我先核對簡報，
別讓大家拿舊數字討論。
報表v3今天 14:00業務會議簡報 v2
Agent · 對照這個「想到」
職責 × 現況 → 推導值得先比對，
有差異再提案。
Event · 報表異動角色：會議支援

主動性，在於自己產生「值得做的事」。

從人的「想到」，拆到 Agent 的實作

人看到新報表，聯想到下午會議與自己在意的會議品質，於是產生「先核對簡報」的工作。也可能只是時間快到了，便想起要檢查。這是理解主動性的情境類比，不是人類認知的完整模型。

對 Agent：Time／Event 決定何時有機會觀察；角色、記憶與現況提供聯想材料；推論產生候選工作，再依證據與權限選擇查證、提案或不動作。排程本身不會替它想到工作。

還有第三種嗎？執行中的 loop 怎麼算？

外部喚醒可用 time／event 描述；已在執行的程式，也可以直接進入下一輪。把「上一輪完成」抽象成內部 event 可以，但實作可能只是 while 迴圈，沒有 timer 或 event bus。記憶、環境、好奇心是判斷輸入／策略，不是第三種神祕喚醒源。

往下拆：喚醒、產生想法、選擇與執行，各負責什麼？
Time／Event：何時開始觀察？

排程、來源事件或內部完成事件提供執行機會。只有 timer 與 queue，還不能證明系統會發現新的工作。

Generate／Select：如何想到與選出工作？

把可存取的現況、職責與記憶放入 context，讓模型推導「有什麼值得處理」，以證據與政策篩選。可以直接提出一件事，不必實作獨立候選池或數值排名器。

查看選題研究與框架邊界 ↗
Execute／Continue：想到之後如何做完？

這是後段能力：工具、授權、任務狀態與 loop 讓選定的工作完成。接續既定目標，是與「發現一件值得做的事」不同的能力。

Polling、Heartbeat、Cron 不是三種觸發器？

Polling 是取資料的方法；Cron 是排時刻的方法；Agent Heartbeat 是週期喚起「看一看」的回合。可以用 cron 排 heartbeat，再在回合內 polling。它們可以疊在一起。

Event 一定比 polling 好？

Push 可降低延遲與無效查詢，但要處理重送、亂序、漏接與訂閱續期。沒有可靠 push 的來源用有界 polling；事件接入也可保留補查。Claude Code 的 Telegram channel 底下也會 polling，所以「模型收到 event」不代表來源端完全沒輪詢。

Voyager 看 environment，不也是時間到讀 context？

查到的 learn() 是 while → 選題 → rollout → 更新紀錄 → 下一輪；不是每隔 N 分鐘選題。wait_ticks 讓環境動作穩定，API 重試也可能 sleep；它們不是選題 cron。

直接看 learn() ↗
所以除了 time／event，還有什麼？

若只談喚醒，time／event 足夠描述本架構；若談整個執行系統，還有持續迴圈。若談「做什麼」，還有目標判斷、curriculum、記憶與提案政策。三個層次不能混成同一份觸發清單。

每次 heartbeat 都花模型費嗎？

不一定。先用確定性准入與來源差異擋掉無效回合；Hermes monitor 在 hash 未變時跳過模型。「零模型」仍有 I/O、CPU 與服務成本。

為什麼舊研究打勾，新表卻寫「未證」？

準則與版本不同。此表要求可用介面，且把目標續跑與自行推斷跟進分開。以來源版本說話；某段 durable goal 資料結構存在，不代表該部署已接上自動續跑。

落地契約：讀什麼、誰寫、何時停止？

進 context

role_card ＋ cursor 必讀；事件命中才讀 kanban／memory／知識庫。沿原設計：必讀約 ≤4,000 字，總量 ≤32,000 字；是字數，非 token。

可寫範圍

audit 每階段記；proposal／inbox 在 W6；journal 與 cursor 在 W7。kanban 只產 diff；對外寄送不接入此情境。

硬邊界

啟動 goal 之前檢查預算；token／時間／回合自行計數。拒絕、延後、取消與耗盡分開，不靠模型自述完成。

W2 身分投影、W3 對帳是原 repo 指出的缺口；原 repo 驗證結果不等於本平台驗證結果。

三個 Phase，

「Phase 3 業界是零」怎麼讀？

你提供的研究在受查五框架、指定快照與「可調用介面＋從對話自行推斷」判準下，未確認現役完整機制。這不是對全市場永久宣告；Voyager 的環境 curriculum 也不能直接換算為此處的 P3。
