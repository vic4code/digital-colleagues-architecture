04 / MECHANISM RELATIONSHIPS

Cron、Heartbeat、Polling，各自負責不同的事。

TimeScheduler
何時到期→Polling（可選）
讀來源、看變化→Admission
值不值得執行→Agent turn
EventWebhook / Channel
接收資料→Verify / Dedup
驗證來源、去重→Admission
權限、忙碌、預算→Agent turn

Cron排程規則

Heartbeat一種巡檢回合

Polling偵測變化的方法

Goal loop既定目標的續行控制

State change、Process completion、Stream data 都可構成 Event；不代表一定有 Event bus。

13 / ACCEPTANCE

不是有提案就算成功，三種條件都要過。

測試條件PASS · 應有結果FAIL · 不通過
有相關新證據
沒有逐件交辦		提出 C-042 檢視建議
附 N-17 與附件來源		漏提、選錯對象、沒有依據
C-042 改成 B 類
不在公告範圍		不產生該提案
留下不適用原因		條件不成立，仍提原工作
同版本議題已結案不重提；保留處理紀錄已處理又建立相同提案
再故意讓它出錯事件重送 → 只派送一次中途重啟 → 不丟工作、不重提來源失敗 → Error，不能假裝沒變
